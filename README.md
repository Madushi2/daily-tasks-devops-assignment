## Project Description

Daily Tasks is a simple, user-friendly, and responsive web-based Todo List application developed using HTML, CSS, and JavaScript. The application helps users organize their daily activities, manage tasks efficiently, and track their progress.

This project was developed as part of the **Advanced Git & DevOps Team Collaboration Assignment**, focusing on practical software development, version control, team collaboration, and DevOps practices.

The project demonstrates the use of Git and GitHub for collaborative development, feature branching, pull requests, code reviews, merge conflict resolution, automated testing, and Continuous Integration/Continuous Deployment (CI/CD).

## Key Features

- **Add Tasks:** Create and manage daily tasks.
- **Delete Tasks:** Remove unnecessary or completed tasks.
- **Mark Tasks as Completed:** Track task progress using checkboxes.
- **Local Storage:** Save tasks in the browser to maintain data after page refresh.
- **Task Filtering:** View all, active, or completed tasks (planned).
- **Task Counter:** Display the number of remaining tasks (planned).
- **Responsive Design:** Provide a user-friendly interface across different screen sizes.

## Technologies Used

- **HTML5** – Application structure
- **CSS3** – Styling and responsive design
- **JavaScript** – Task management functionality
- **LocalStorage API** – Browser-based data persistence
- **Git & GitHub** – Version control and collaboration
- **Node.js** – Automated testing environment
- **GitHub Actions** – CI/CD automation (planned)
- **GitHub Pages** – Application deployment (planned)

## Project Objectives

The main objective of this project is to develop a functional Todo List application while gaining practical experience in Git workflows and DevOps practices.

The project emphasizes collaborative software development, maintaining a clean commit history, managing feature branches, conducting code reviews, resolving merge conflicts, and implementing automated testing and deployment.
